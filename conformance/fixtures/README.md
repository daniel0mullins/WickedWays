# Conformance fixtures

**Rust + TOML are the source of truth.** These files gate `cargo test
--workspace` through four Rust gates; the retired TypeScript engine no longer
generates anything here.

## The pipeline

```
{name}.toml ──(wickedways-author compile)──▶ {name}.description.json + {name}.catalog.json
                                                        │
                                             (wickedways-assemble assemble)
                                                        ▼
                                              {name}.genesis.json / *.snapshot.json
                                                        │
                                        (wickedways-core replay: commands/ops/sync)
                                                        ▼
                                              {name}.golden.json
```

## File classes

| Class | Files | Regenerated by |
|---|---|---|
| **Source** | `*.toml` | hand-authored — never generated |
| **Compiled** | `{name}.description.json` + `{name}.catalog.json` for every TOML | `UPDATE_GOLDENS=1 cargo test -p wickedways-author --test gate` |
| **Assembled** | `*.genesis.json`, `hollow-house.snapshot.json`, `seed.snapshot.json` | `UPDATE_GOLDENS=1 cargo test -p wickedways-assemble --test goldens` |
| **Replay pins** | `*.golden.json` (command + facade families) | `UPDATE_GOLDENS=1 cargo test -p wickedways-assemble --test replay_gate` |
| **Sync pins** | `sync-*.golden.json` | `UPDATE_GOLDENS=1 cargo test -p wickedways-assemble --test sync_gate` |
| **Frozen inputs** | `*.start.snapshot.json`; the `description.json`/`catalog.json` pairs with **no** TOML source (the `facade-*`/replay families) | nothing — checked-in recordings from the retired TS era, now plain inputs. Edit only deliberately. |

## Regenerating

Goldens are regression pins of the Rust engine's own output. When a change
intentionally alters behavior:

```bash
UPDATE_GOLDENS=1 cargo test -p wickedways-author  --test gate
UPDATE_GOLDENS=1 cargo test -p wickedways-assemble --test goldens
UPDATE_GOLDENS=1 cargo test -p wickedways-assemble --test replay_gate
UPDATE_GOLDENS=1 cargo test -p wickedways-assemble --test sync_gate
```

Review the diff like code, then commit it. Regeneration is deterministic:
running any of the above a second time must produce a **zero git diff**.
Recorded inputs (seeds, command/op streams) are preserved verbatim; only
outputs are rewritten.

(The retired TypeScript generators that originally emitted this corpus have
been deleted along with the TS engine; the Rust gates above are the only
producers and consumers now.)
