# Crafting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add recipe-based crafting — materials → regular items and keys → higher-tier keys — with party-wide recipe discovery and a free `Character.craft`.

**Architecture:** A first-class `CraftingRecipe` (id, input cost, `create()` factory) in a new `crafting.ts`. Known recipes live party-wide on `Campaign` (`#knownRecipes`), seeded at construction and grown by picking up items that `teaches` a recipe, or via a `discoverRecipe` primitive. `Character.craft(recipeId)` validates all-or-nothing, spends inputs (pool materials or held keys), and produces the output via the low-level `receiveItem` so it costs no action.

**Tech Stack:** TypeScript (strict, NodeNext), Vitest, ESLint. Branded ids via `Brand<T, TBrand>`; discriminated unions for the two recipe tracks.

**Spec:** `docs/superpowers/specs/2026-06-09-crafting-design.md`

**Depends on:** sub-project ① material economy (`Campaign.canAfford` / `withdrawMaterials` / `claimMaterials`) and the key system from PR #13 (`createKey`, `consumeKey`, the free keyring). This branch (`feature/crafting`) is stacked on `feature/material-economy`.

---

## File Structure

- `src/lib/crafting.ts` *(create)* — `RecipeId`, `KeyCost`, `CraftingRecipe`. Pure types; imports `Brand`/`IItem`/`MaterialMap` **type-only** to avoid a runtime cycle with `inventory.ts`.
- `src/lib/inventory.ts` *(modify)* — add the optional readonly `teaches?: CraftingRecipe` field to `IItem` / `Item` and its constructor.
- `src/lib/campaign.ts` *(modify)* — `#knownRecipes` map, `knownRecipes` getter, `knows`, `discoverRecipe`, and a constructor seed parameter.
- `src/lib/character/character.ts` *(modify)* — discovery wiring in `addToInventory`; the `craft` method (item track then key track).
- Tests live beside each source file (`*.test.ts`), plus a new `src/lib/crafting.test.ts`.

**Build order:** types (1) → known-recipes on campaign (2) → `teaches` field (3) → discovery wiring (4) → craft item track (5) → craft key track (6).

```ts
import { Brand } from "./brand";
import type { IItem, MaterialMap } from "./inventory";

/**
 * Author-chosen recipe identifier (semantic, like a key's code, but branded so a
 * stray `string` can't be passed where a recipe id is expected). Authors cast
 * their literal at the boundary: `"iron-sword" as RecipeId`.
 */
export type RecipeId = Brand<string, "RecipeId">;

/** A quantity of keys a key recipe consumes, matched by code. */
export type KeyCost = { keyCode: string; qty: number };

/**
 * A crafting recipe: an id, an input cost, and a factory for the output. Two
 * shapes, mirroring the engine's item/key split — a `materials` recipe produces a
 * regular slotted item; a `keys` recipe produces a (free) key. Craft logic
 * discriminates with `"materials" in recipe`.
 */
export type CraftingRecipe =
  | { id: RecipeId; materials: MaterialMap; create: () => IItem }
  | { id: RecipeId; keys: KeyCost[]; create: () => IItem };
```

(`IItem` and `MaterialMap` are imported `type`-only; `inventory.ts` will reference `CraftingRecipe` `type`-only in turn, so the cycle is erased at runtime.)

```ts
  discoverRecipe(recipe: CraftingRecipe) {
```

```ts
  addToInventory(item: IItem | IItem[]) {
    const items = Array.isArray(item) ? item : [item];
    for (const current of items) {
      if (current.type === "key") {
        // Keys never consume a slot, so they bypass the room check entirely.
        this.receiveItem(current);
        current.actions.pickUp(this);
      } else if (this.hasRoomForItem()) {
        this.receiveItem(current);
        current.actions.pickUp(this);
      } else {
        throw new ProceduralViolation(
          "Attempted to add to inventory, but character doesn't have enough slots!",
        );
      }
      // A picked-up item may impart a recipe to the whole party.
      if (current.teaches) {
        this.campaign.discoverRecipe(current.teaches);
      }
    }
    this.recordAction(this.addToInventory, {
      kind: "pickUp",
      items: items.map((i) => ({ id: i.id, name: i.name })),
    });
  }
```

```ts
  /**
   * Crafts the output of a known recipe into this character's inventory. Free —
   * it does not consume a budgeted action (it uses the low-level `receiveItem`,
   * not `addToInventory`). Validates everything before spending, so a rejected
   * craft mutates nothing.
   *
   * @param recipeId - The recipe to craft; must be known to the party.
   * @returns The crafted item.
   * @throws {@link ProceduralViolation} if the recipe is undiscovered, the pool
   *   cannot afford a materials recipe, or there is no slot for the output.
   */
  craft(recipeId: RecipeId): IItem {
    const recipe = this.campaign.knownRecipes.get(recipeId);
    if (!recipe) {
      throw new ProceduralViolation("Cannot craft an undiscovered recipe");
    }
    if (!("materials" in recipe)) {
      // Key crafting arrives in the next task.
      throw new ProceduralViolation("Key crafting not yet implemented");
    }
    if (!this.campaign.canAfford(recipe.materials)) {
      throw new ProceduralViolation("Not enough materials to craft");
    }
    if (!this.hasRoomForItem()) {
      throw new ProceduralViolation("No inventory slot for the crafted item");
    }
    this.campaign.withdrawMaterials(recipe.materials);
    const output = recipe.create();
    this.receiveItem(output);
    return output;
  }
```

```ts
    const recipe = this.campaign.knownRecipes.get(recipeId);
    if (!recipe) {
      throw new ProceduralViolation("Cannot craft an undiscovered recipe");
    }

    if ("materials" in recipe) {
      if (!this.campaign.canAfford(recipe.materials)) {
        throw new ProceduralViolation("Not enough materials to craft");
      }
      if (!this.hasRoomForItem()) {
        throw new ProceduralViolation("No inventory slot for the crafted item");
      }
      this.campaign.withdrawMaterials(recipe.materials);
      const output = recipe.create();
      this.receiveItem(output);
      return output;
    }

    // Key track: inputs are keys held in the keyring; the output is a free key.
    // Verify every required code is fully covered before consuming anything.
    for (const { keyCode, qty } of recipe.keys) {
      const held = this.#inventory.keys.filter((k) => k.keyCode === keyCode);
      if (held.length < qty) {
        throw new ProceduralViolation("Missing required keys to craft");
      }
    }
    for (const { keyCode, qty } of recipe.keys) {
      const held = this.#inventory.keys.filter((k) => k.keyCode === keyCode);
      for (const key of held.slice(0, qty)) {
        this.consumeKey(key);
      }
    }
    const output = recipe.create();
    this.receiveItem(output);
    return output;
  }
```
