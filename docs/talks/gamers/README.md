# Talks for Gamers: One Game, Every Table

The same story as the [technical talk set](../README.md), reformulated for a
**non-technical audience** — gaming enthusiasts, tabletop players, convention
crowds. No programming background assumed, ever: no code, no library names,
no architecture diagrams. The engine becomes "the game's one brain," the
sync layer becomes "the referee," and the talks lead with what players
actually feel: the haunted house, the dice, the physical board, and the
promise that the game plays *identically* everywhere.

## The pitch, in gamer terms

Every digital board game you've played has the same quiet problem: the app
plays a little differently than the tabletop version, the tutorial teaches a
third set of rules, and the port on your friend's console is its own thing.
Wicked Ways has exactly **one** set of rules — one brain — and every way of
playing is a window onto it: browser, desktop app, online with friends, or a
real physical board with repainting e-ink tiles, pieces the board recognizes,
and **your own dice**. Roll a real d20 and the game takes your roll — and the
session is still perfectly replayable, because every roll is written into the
game's ledger. Saves never lie, nobody can cheat, and campaigns are readable
text files — the campaign we ship is written exactly the way a fan-made one
would be. Goal, stated out loud: **as moddable as DOOM.**

## Conventions for speakers

- These talks avoid technical vocabulary entirely; where one concept must be
  named (e-ink, NFC), it gets a five-word gloss and moves on.
- Facts must stay true to the repo, same as the technical set — the two sets
  describe one system. When the engine changes, update both.
- The decks embed each talk's script as per-slide speaker notes.
